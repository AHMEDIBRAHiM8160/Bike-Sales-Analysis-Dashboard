# 🚲 Bike Sales Analysis Dashboard - Excel

## 📊 Project Overview

This project presents an end-to-end **Bike Sales Analysis** conducted using Microsoft Excel.

The project focuses on transforming a raw customer dataset into meaningful insights through:

- Data Cleaning
- Data Preparation
- Pivot Table Analysis
- Data Visualization
- Customer Segmentation
- Interactive Dashboard Development

The analysis explores customer demographics, income, education, marital status, gender, commute distance, and other customer characteristics to understand patterns associated with bike purchases.

This project demonstrates my practical ability to take a raw dataset, prepare it for analysis, perform exploratory analysis, and communicate findings through an interactive business dashboard.

---

## 🎯 Project Objectives

The main objectives of this project were to:

- Clean and prepare the raw bike sales dataset for analysis.
- Standardize inconsistent categorical values.
- Organize the dataset into an analysis-ready format.
- Analyze customer characteristics and purchasing behavior.
- Use Pivot Tables to summarize important business metrics.
- Create charts to identify patterns and trends.
- Develop an interactive Excel dashboard.
- Present data-driven insights in a clear and professional format.

---

## 🗂️ Dataset

The dataset contains customer-level information related to bike purchases.

### Key Variables

| Variable | Description |
|---|---|
| ID | Unique customer identification number |
| Marital Status | Customer's marital status |
| Gender | Customer's gender |
| Income | Customer income |
| Children | Number of children |
| Education | Customer education level |
| Occupation | Customer occupation |
| Home Owner | Whether the customer owns a home |
| Cars | Number of cars owned |
| Commute Distance | Customer's commuting distance |
| Region | Customer's geographical region |
| Age | Customer age |
| Purchased Bike | Whether the customer purchased a bike |

## 🧹 Data Cleaning & Preparation

The raw dataset was reviewed and transformed into a structured working sheet before analysis.

The cleaning and preparation process included:

- Reviewing the original dataset for inconsistencies.
- Standardizing categorical values.
- Converting abbreviated values into readable labels.
- Preparing customer attributes for analysis.
- Creating additional analysis-friendly fields.
- Organizing the cleaned data into a structured worksheet.
- Checking the dataset before creating Pivot Tables and visualizations.

### Data Preparation Flow

**Raw Data → Data Cleaning → Working Sheet → Pivot Tables → Visualizations → Dashboard**

## 📈 Key Analysis Areas

### 1. Income Analysis

The dashboard compares income levels across genders and bike purchase status to identify differences in purchasing behavior.

### 2. Customer Age

Customers were grouped into age brackets to examine how age relates to bike purchasing behavior.

### 3. Commute Distance

Commute distance was analyzed to understand whether customers living or traveling different distances are more likely to purchase bikes.

### 4. Customer Demographics

The analysis considers demographic characteristics such as:

- Gender
- Marital Status
- Education
- Region
- Age

### 5. Purchase Behavior

The central focus of the analysis is understanding the characteristics of customers who purchased a bike compared with those who did not.
